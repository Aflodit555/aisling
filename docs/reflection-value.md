时间投影明确区分 formedAt 与来源消息时间，保留角色、局部会话标签、位置、粗略时间／unknown，供模型结合原文判断冲突。旧模式若只有单次用户报告加角色复述，现会被 Recall 排除，但不修改旧文件。新增字段占用既有预算，长候选可能整体省略；不截断原文、摘要或不确定性。

## 开销与未解决问题

普通回复没有新增 Provider 请求，不等待 Formation。每个形成批次多一次有界本地历史检索和有限摘要／预算检查；仍是一条原有后台形成请求。Recall 在缓存失效时构建索引，每轮只处理查询、排名和最多六条候选的来源核验；未做设备级延迟基准，不宣称具体毫秒改善。

持久化只增加新 Reflection 实际引用的少量历史 sourceRefs，仍最多 12 条、同一 2 MB 文件上限；不复制历史原文，不增加索引文件或版本迁移。请求里的时间／scope 不写入 Schema。元数据会减少同预算可装入的候选正文。

仍不能解决词项完全不同的语义关联；历史大组放不下或扫描超限时可能错失模式；现有相关旧 Reflection 候选仍是有限词项匹配，重复认识只能靠形成模型自律。不同消息不一定是不同经历，SHA-256 只证明原文未变，不能证明概括、动机或因果正确。旧数据缺时间、时钟失准、未召回更新、候选第六条以后的有效来源及真实 Provider 的审核／输出波动仍有限制。本次没有实现 Memory Organization／Evolution，也没有新增公开设置或依赖。

### 规则与取舍

保留现有 BM25、话题门槛和最多六条来源核验池。候选经过角色、安全、SHA-256、模式证据／不确定性检查后，序列化为完整投影；时间、位置、来源和不确定性均不精简、不截断。枚举至多三条的 41 个非空子集，先检查 JSON 数组的字符和 UTF-8 字节成本，再在可行组合中取最大价值。

价值为组合内归一化 BM25 之和。在比较、想／计划做任务却遇阻、反例或适用边界类提问中，额外取组合内最高的模式范围收益：`log2(max(1, min(不同用户来源数, 不同具体标签数)))`。仅已相关且来源有效、有不确定性的 pattern 参与；普通事实问题不获得这一收益，不依据 Reflection ID 或完整问题句子特判。意图仅是小范围词项／措辞启发式，没有引入独立分类器、模型调用或通用优化框架。

相同 kind、一个来源集合包含另一个且正文有意义双字／拉丁词项的包含度至少 70% 时，对该候选对扣除较高的归一化相关性，减少重复收益；不同日期／不同来源的状态更新不会仅凭同主题被当作重复。每组模式范围收益只计算最高一项，避免多条重复模式叠加奖励。价值差在 1e-9 内时选择 UTF-8 成本更小的组合，剩余平局按已有稳定候选顺序处理。

Runtime 使用同一轮已核验快照的 `select(fits)` 在实际剩余估算 token 空间重选，策略文本和消息 framing 计入成本；不再次解析整个存储或计算来源摘要。候选最多三条、1500 字符、4500 字节及输入总上限均保持原值。没有原始 Recall 时跳过一次原先重复的相同预算选择；联合模式仍沿用至多一半剩余空间预留和原始整组装包规则。

### 验证、诊断及限制

新增的生产函数测试覆盖两种时间条件的三题、相关具体事实、重复信息取舍、单一主题不能靠引用数量放大范围收益、最大 41 组合、缺失／改写来源、新 Session 不替代旧来源、无相关结果、候选不足及全无效。测试还覆盖 Runtime 实际剩余预算、JSON／数量／字节验证、完整不确定性、固定快照和同一输入的确定性；三题 A/B/C 对照中，C 的原始 Recall 块与 A 完全一致。选择器异常或自定义非法输出不会破坏普通回复。

诊断沿用 context-assembled，补充最多六条 `reflectionSelection`。候选分别标注 relevance、invalid-source、selected、candidate-budget、context-budget 或 combination-value，附 topical、eligible、成本与最终顺序。本地 Store 额外提供 reflectionId 以便人工对照；持久日志只接受临时 R 标签和已白名单化的数值／枚举，不包含摘要、原文、sourceRefs 或内部 Reflection ID。

组合阶段只处理最多六个候选，不扫描历史，不新增实时 Provider 请求。会核验整个有界候选池，而不在找到三条后提前停止，常见情形可能多核验少量来源；上限仍为六候选、72 引用，同一消息每轮只 hash 一次。一次本机热身后 500 次六候选选择函数微测量：中位约 0.138 ms、P95 约 0.319 ms。此数字不包含索引、来源哈希、Runtime 和 Provider，不构成端到端延迟保证。

没有执行真实 Provider 语义验证，不宣称回答质量已经改善。意图、词项相似度和证据范围收益都是有限启发式，不能证明独立经历、因果或真实适用范围；候选池以外的认识仍可能漏召回。重复惩罚可能错判细微区别，时间元数据仍占用预算，极小 Context 仍会省略记忆。自动测试结果见本阶段交付报告。
