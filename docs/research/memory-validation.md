# Memory 与 Reflection：有限验证记录

本页保留影响工程判断的研究结论，不是持续运行的实验指南。当前 Note v2 行为见 [Memory](../memory.md) 和 [P6](../memory-organization-p6.md)；旧 Profile 兼容行为见 [Formation](../memory-formation-v0.md) 和 [Reflection Recall](../reflection-recall.md)。原始本地日志、真实用户文件和独立研究目录不随源码发布。

## 形成结构与语义分开判断

Schema、E/R 引用、来源 SHA-256 和原子提交的确定性测试只能证明记录符合契约，不能证明概括忠实、模式稳定或关联有意义。零条产物是允许的模型结果；Provider 失败不是模型决定不形成。

早期八个固定合成样本涉及低价值确认、OCR 状态变化、误判纠正、旧照片、自我发言、用户与角色偏好区别、出售与价格、候选关联。首个请求 HTTP 401，后续七个停止；不能把这组样本称为真实形成语义验收通过。没有为通过验收而修复输出、猜引用、重试鉴权或放宽校验。

后续诊断定位过 related 未通过数组校验。模型契约现明确每条都必须提供 related，无关联时为 []；解析器继续拒绝缺失、null、字符串、对象等情况。没有保存旧原文时，不能进一步断言模型究竟省略还是输出了 null。

## 2026-10-27 定点真实 Provider 样本

使用当时配置的 qwen3.8-flash、隐藏 Electron 和独立临时 userData，在同一新 Session 提供三轮合成经历：练完整首手碟未开始、缩为两分钟节奏完成；另一次缩为一个小节完成；画完整场景未动笔、缩为一个杯子完成。

总共 7 次真实请求：3 次前置普通回复、1 次 Formation、A/B/C 各 1 次。没有重试或参数修补。Formation HTTP 200、finishReason=stop，正文 1015 字符、推理 2901 字符，请求约 22.9 秒。

一个 completed 批次保存 3 条 Reflection：一条 pattern/mixed 概括大目标难开始、缩小后完成；一条手碟练习事件；一条角色幽默回应记录。模式带有“仅依据三次报告，不能确认长期稳定模式”的不确定性。独立文件及 8 个来源引用 SHA-256 回查通过，真实用户文件哈希前后相同。

关闭 Formation，固定来源与产物，针对同一问题“练手碟和画画这几次，有没有什么相似的地方？”进行：

| 模式 | 原始证据实际注入 | Reflection 实际注入 | 观察 |
| --- | --- | ---: | --- |
| A | 是 | 0 | 从原文答出大目标与小任务的共同模式 |
| B | 否 | 3 | 仅靠历史认识也答出相似点 |
| C | 是 | 3 | 联合材料同样答出相似点 |

B/C 的 Reflection 消息共 1988 字符、2444 个保守估算单位，包含固定策略。结果说明这一次真实形成与 Recall 链路可用；A 已经答得较好，因此没有证明 Reflection 的额外回答收益、统计稳定性或长期质量。

这是同一 Session 的多情境形成，不是自动合并多个旧 Session 的验收。没有加入购买状态更新，不能宣称“尚未买／已买”冲突处理的真实模型体验通过。另一次自然发生的 invalid-output 没有留下具体字段，随后这次没有复现，原因仍未知。

## 2026-10-28 失败与恢复的收束结论

当时五批形成失败，最小修复后的首次真实复验仍被当前来源约束拒绝；不能把失败期记成链路通过。后续恢复为4／5批 completed、5条已保存 Reflection，另1批缺少 related 而保留 failed，未绕过校验或拆批保存。

恢复后另做33次真实 A/B/C 对照，实际注入条件成立；支持链路可用和认识输入更紧凑，尚未证明 Reflection 有可重复的总体净收益。早先零 Reflection 的回答没有混入这33次结果。独立故障、工程及 A/B 报告已清理，以上结论不代表当前 Note v2 或 P6 的语义验收。

其中绘画样本的人工审阅被旧实验包装器错误放入45秒等待链，联机等待超时；之后复用同一完整真实响应，经生产解析、验源、原子保存与新Store回读，不是连续桌面联机闭环成功。其余成功批次与这次响应回放分开判断。候选组合曾漏选可放入预算的跨经历Pattern，导致仅靠Reflection的比较回答缺少绘画依据；没有改原文、拆批或继续调参把失败改记为通过。

## 旧 Note v1 / Organization 阶段的保留结论

P1.2–P1.8的实验支持复用一次调用做候选、按来源验证和受限写入，不支持开放一般Evolution。旧24场景中B/C各21次动作目标正确，新场景为10/12与9/12，均出现严重误取代；C约用B的49%输入Token只说明该对照的成本差异。一次P1.7真实组织调用为1624 tokens，普通回复仍为Mock，不是完整真实对话验收。

这些结论以及旧删除/版本审计推动了后续Note-only收束。当前Note v2以直接Evidence、独立权威、Revision/Receipt、持久删除屏障与受限授权取代旧写入路径；旧兼容、迁移和历史擦除仍须保留。整份Profile回滚、真实物理磁盘擦除和长期大库行为不由这些阶段实验或当前合成回归证明。

## 延迟调查保留的结论

普通对话、形成和 P2 的策略应分别判断。现有精确匹配路线会对特定 qwen3.7-flash 普通文字轮关闭 thinking；不推广到其他模型，也不改变后台形成或自主回复。用户当时报告延迟改善，但缺少可推广的质量／延迟统计结论。当前参数及边界见[思考策略](../consciousness-thinking.md)。

一次性 Memory/TTS 延迟分析器、事件循环探针和重复计时不再属于正式路径。保留的是资源预算、错误、交付、必要诊断与取消生命周期测试；不能把性能埋点的删除当作正式功能覆盖的删除。
