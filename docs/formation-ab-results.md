## 单批闭环与保留的限制

旧 E7 是原 BM25 整会话检索带入的购买状态，不是绘画模式所需证据。Formation 现在只在当前用户报告含尝试／目标及结果时补充同类相关经历，状态类批次只用当前证据。原绘画投影排除了 E7/E8，其余六条的原文、角色、ID、时间、位置及摘要与冻结快照一致。请求列出 currentBatchSources 和仅供 Pattern 支持的 relatedPatternSources；不要求凑类别，不把共现写成确定因果。没有改 Schema、解析器、SHA-256、原子性、1500 token 或普通聊天配置。

真实绘画请求返回 1 条 Pattern，来源是当前绘画加两次手碟用户报告，保留不确定性，无独立旧购买状态。此次人工审阅等待被实验脚本错误地放在 45 秒 Provider 等待链内，使调用超时。**不能把这次称为一次连续联机闭环成功。** 没有重发同一请求：人工审阅后，将同一完整原始响应原样送入生产解析、结构校验、来源复核、原子提交和新 Stage／新 Store 回读，得到合法产物；未改内容、未拆候选、未绕过拒绝路径。

Electron 后续启动的自动审批两次超时未执行。Node 沙箱 DNS 返回 ENOTFOUND；提升网络权限后的不带认证 HEAD 返回 404，证实连接可达。最终恢复及 A/B/C 用 Node 入口运行生产 Pinia Stage、Formation、Recall、Runtime 和 Provider，文件后端在新隔离目录，保持同一模型端点及请求 JSON 参数。其他三批成功的真实联机请求直接完成保存与新 Store 回读。因此，这里区分真实模型产物、完整响应回放和 Mock，不宣称完成桌面 UI 端到端复测。

## 回答判断与错误

沿用原 criteria.json，人工逐条审阅，未使用额外 LLM 裁判，未盲评。pass=核心要求满足，partial=部分正确但缺少依据／边界或有未证实解释，fail=明确事实／来源错误。一般拟人比喻不单独算事实错误，未经确认的心理原因和历史数量变化另记。每组样本很少且 temperature 较高，以下计数不是统计显著性或总体胜率。

| 题类 | A 通过／部分／失败 | B 通过／部分／失败 | C 通过／部分／失败 |
| --- | --- | --- | --- |
| 事实（每组 1 次） | 1／0／0 | 1／0／0 | 1／0／0 |
| 状态（每组 1 次） | 1／0／0 | 1／0／0 | 1／0／0 |
| 比较（每组 3 次） | 1／2／0 | 0／3／0 | 2／1／0 |
| 迁移（每组 3 次） | 1／2／0 | 0／2／1 | 3／0／0 |
| 反例（每组 3 次） | 3／0／0 | 1／2／0 | 1／1／1 |

事实／状态三组都答对：没有把局部练习说成整首完成，识别后来已购买及当前更想绘画。A 也能从原文组织共同关系，不能将 B/C 同样正确算成独立认识增益。

比较题的关键漏选可直接由诊断解释：P2 通过来源及话题门槛，但 6 次 B/C 都选择了 P1+S1。P2 单独能放下（1105 字符），其 BM25 为 3.0051；P1 为 3.8524，S1 为 2.7883，组合价值函数偏向后两者，再把 P2 标为 candidate-budget。这不是旧来源失效，也不是 P2 从未形成。B 实际拿不到绘画杯子经历，三次都停留在泛化或补出“画画只勾一笔”等未报告细节。C 有原始绘画证据，弥补了这项遗漏。本轮未据结果再改 Recall 或重测。

迁移题中 C 三次都能联系手碟／杯子并提出一句／两句写作起点，是联合使用的有限积极观察。A 也有成功迁移；B 常给泛化建议，第二次更把“一小节／两分钟”说成“练两小节”，是明确数量错误。不能由输入中有正确 Pattern 就推定模型忠实使用了它。

反例题中 A 三次保留过去有效与此次未完成的区别。C 第一次说“把‘缩小必完成’降级”，但原文和 Pattern 从未保证必然完成；还猜测本次是手碟懒得动。B 的“必杀技”等表述也夸大了旧认识。C 第三次“之前完成过是真的，这次没完成也是真的”则正确。这说明不确定性被注入不等于能稳定约束回答，不能预设 Reflection 优于原文。

**真实增量价值的结论：** Reflection 可以在更紧凑的输入中独立支持事实／状态和部分经验迁移；联合模式在迁移题上较完整，但存在新的错误和比较任务漏选，没有形成可重复的总体净收益证据。当前限制是形成合规性仍非百分之百、候选组合与问题需求不完全一致，以及模型对有限认识的解释波动。本任务至此结束，不扩展架构或继续消耗 API 调参。
