# Context 与会话持久化

本文描述当前实现。早期验证、性能测量和原生冒烟限制见[研究记录](research/context-validation.md)。

## 模型窗口

`packages/core/src/context.ts` 为每次 Provider 请求选取上下文。UI 和持久化保留完整会话；模型只看到连续的、完整交互组成的近期后缀。

| 项目 | 本地估算预算 |
| --- | ---: |
| 总窗口策略 | 16384 |
| 输出预留 | 1024 |
| 安全余量 | 1024 |
| 最大输入 | 14336 |
| 当前 Session 历史 | 最多 4096，且受剩余输入空间限制 |

估算采用 UTF-8 字节数加每消息 framing，不是 Provider tokenizer 或通用上界保证。工具定义、工具调用和结果、历史自主依据都计入预算。更小窗口的自定义模型仍可能拒绝请求。

Persona、当前请求、必要策略及本轮工具反馈先占用必需空间，再选择历史。原始 Recall 与 Reflection 使用其后的剩余空间，不挤掉已选择的 Session 历史。双源细则见 [Reflection Recall](reflection-recall.md)。

以用户输入为单元边界，工具请求与结果必须引用完整；自主发言与其依据也一起选择或省略。最近完整单元过大时可能没有历史入选。必需输入超限会明确失败，不发下一次请求、不截断结构化数据、不删除存储内容。

Runtime 最多执行四轮工具调用，之后允许最后一次回答请求；若该请求继续要求工具，则拒绝执行。工具失败通过正确关联的 tool 消息反馈，失败轮不提交为已完成历史。

## 已交付自主发言

普通用户回复可使用已交付自主发言及精简 `autonomousContext`。自主生成本身仍只使用当前候选，视觉轮也不启用跨 Session Recall。

依据保存实际交付时间、可用的观察时间、来源、变化类型，以及经过白名单与脱敏的应用、标题、歌手或片段。前台片段最多 240 字符，不保存完整 UIA、Snapshot、模型推理或 P2 claims。取消、失败和空输出不保存为已交付发言。

入选历史时，依据投影为紧邻 assistant 发言之前的历史数据消息，明确其不可信、并非当前桌面。最终 Provider 消息只保留协议字段，不携带内部持久化字段或 Candidate／对象 ID。

## 时间与状态

Stage 在实际追加用户输入、最终回复、自主回复及本地命令确认时记录可选 `createdAt`。部分流式文本不独立持久化；旧消息不补写当前时间。旧会话缺少合法时间时以 0 表示未知，列表显示破折号，旧单会话迁移也不把迁移时刻当历史时间。

普通 Context 不发送持久化时间附件。跨 Session 原始 Recall 的时间投影、稳定排序和事件时间限制见 [Memory](memory.md)。Reflection 的形成时间不是事件时间。

## 保存、恢复与错误

浏览器使用 localStorage，Electron 使用 `userData/aisling-store.json`。同一会话的 UI、Runtime 和持久化边界由 Stage 协调，切换／新建会话重置 Runtime 历史；本地模式命令不会取消正在进行的普通回复。

- 写入失败：保留完整待保存内存状态，显示警告；后续会话变更重试整体保存，成功后清除错误。
- 读取失败：保留最后已知状态，并禁止当前实例覆盖未知存储；不使用空状态覆盖损坏或不可读文件。
- Electron：严格读取后合并，写临时文件成功才 rename；同步桥以 false 报告失败。
- 旧单会话迁移：首次成功保存前保持迁移身份稳定；不限制恢复为 50 个会话，不静默裁剪旧记录。
- 空最终回复：保留用户输入，撤下流式临时文字，不保存空 assistant，也不触发语音、情绪或 Formation。

存储失败警告不代表磁盘数据已删除。重启会丢失尚未成功保存的内存修改。完整 JSON 的同步解析和整文件保存随数据量增长；没有数据库事务、fsync 级断电保证、多写入者锁或无限容量承诺。
