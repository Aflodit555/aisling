## 审计范围与决定

按单用户、单 renderer 写入者的现有使用边界，检查了工作区 diff、运行入口、配置／迁移、存储、Formation、Recall、Context、工具轮、TTS 生命周期、Desktop IPC／诊断和对应测试。Live2D／原生采集行为沿用固定资源和子模块，没有借本次收束重新设计。

| 分类 | 决定与依据 |
| --- | --- |
| Formation／Reflection store／Recall 与新增测试 | 保留为正式实现；覆盖状态、来源 SHA-256、后台取消、错误隔离、读缓存、预算和快照 |
| 消息时间／旧格式兼容／Recall 时间投影 | 保留现有工作区实现和测试；不把旧迁移或 Session 更新时间当事件时间 |
| Context、Runtime、TTS、Browser Speech 修复 | 保留用户已有实现；实验计数的删除不改变工具上限、持久化、取消、播放状态及释放边界 |
| A/B/C Console 入口 | 保留开发诊断和测试；不持久化、不新增公开设置，Memory OFF 仍优先 |
| Context 两篇重复说明 | 合为当前 Context 文档；旧加固说明删除，有用测量与反例转入 research/context-validation.md |

| 其他 .local、真实 userData、仓库外研究目录 | 不删除；用途混合或仍有证据价值，继续忽略，不打包或推送 |
| Live2D 纹理、模型、原生子模块、四个现有 Electron 冒烟入口 | 保留；均服务现有产品或不同运行条件，不按体积／文件数量清理 |

本轮没有删除任何产品测试，也没有修改审计开始时的生产 TS／Vue／CJS 实现。此发布收录 v0.3.6 后已完成的工作区功能；本轮清理只处理版本元数据、忽略规则和文档／本地一次性工具。

## 配置、来源及默认值

- Memory 默认开启；旧明确 opt-out 保留。Formation 默认关闭，受主开关约束；只停 Formation 仍可读已保存认识。
- Formation v1 Schema、独立 JSON 文件、批次状态及 sourceRefs 不迁移；形成状态与产物一次提交，错误不覆盖损坏文件。
- 新消息可选追加时间保留，旧消息不补写当前时间。来源哈希覆盖完整标准化记录，新增记录不重写旧来源。
- 普通文字轮固定已保存 Reflection 快照；无关、来源失效、读取错误或预算不足时安全省略。模型仍可能误解历史材料。
- Persona、候选生成、Live2D、Desktop Awareness 及 Thinking 的已存在路线边界保持；没有为发布新增实时 Provider 调用。

## 依赖、版本与发布边界

四个 package.json 和 README 统一为 0.3.7。启动命令、private workspace 属性及原生子模块提交保持不变；没有新增、删除或升级依赖。

初步只看锁文件头部曾误判缺少工作区图。进一步按 [pnpm 双文档格式](https://github.com/pnpm/pnpm/blob/main/pnpm/docs/lockfile.md) 检查：第一段是 pnpm 引导依赖，第二段已含全部工作区依赖。离线 frozen 安装通过，锁文件最终与原文件完全一致，不将此项记为修复。

该版本发布源码和 Git Tag，不生成 installer，不引入签名、自动更新或 npm 发布流程。现有模型资源属于产品，保留；个人配置、Reflection 文件、JSONL、缓存、构建／测试产物继续排除。扫描确认一个凭据匹配来自明确的 Mock 测试字符串，不是真实密钥。
